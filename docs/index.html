Anti-dian is a chat sidebar for Obsidian Desktop. It reads the notes a question needs, proposes edits as diffs, and waits for you to accept them. Your folders, tags and naming stay as they are.

Checked before it lands

In every mode, an edit has to target a path inside your vault, a note that hasn’t changed since it was read, and text that matches exactly one place. Otherwise it isn’t applied.

Undo, one edit at a time

Undo puts a note back to the moment before that edit, so later changes to the same note can be lost. Undo history clears when Obsidian closes.

Conversations you can find again

Each vault keeps its own list. Reopen a conversation and its tool calls and diffs are still there.

Teach it with a Markdown file

Save instructions in .anti-dian/skills/ inside your vault. Anti-dian finds each one by its description and loads it when a conversation calls for it. 

---
name: daily-review
description: Summarize today's notes and extract open action items.
---

# Daily review

1. List the notes changed today and read them.
2. Collect unfinished tasks, grouped by project.
3. Append the result under "End of day" in today's daily note.
4. Leave the existing paragraphs as they are.

Save as .anti-dian/skills/daily-review.md

What leaves your computer

Answers come from Google’s Antigravity backend, through its official CLI. Anti-dian never uploads your whole vault.

Sent to Google

  • The messages you write
  • Images, video and audio you attach
  • The outline of your open note, unless you turn it off
  • Note names, search results and text read during that conversation

Stays on your computer

  • The text of every note a conversation doesn’t read
  • Undo snapshots
  • Titles and pins you give your conversations

If agy isn’t installed, Anti-dian downloads the official binary and verifies its checksum before running it. You can point to your own copy in Settings → Anti-dian → Advanced.

Install

You need Obsidian Desktop 1.7.2 or newer and a Google account.

  1. Add the plugin

    This opens Anti-dian’s page inside Obsidian. Choose Install, then Enable.

    Install in Obsidian

  2. Sign in

    In Settings → Anti-dian, choose Sign in with Google. The backend downloads on first use.

  3. Ask about a note

    Open the sidebar from the ribbon icon, or run Anti-dian: Open sidebar.

Nothing opened? Start Obsidian, then search for Anti-dian in Settings → Community plugins → Browse. To build it yourself, follow the README.

Anti-dian is an independent, open-source plugin. It isn’t made by or affiliated with Obsidian or Google.
